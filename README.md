# VolumeHelper

<img width="629" height="510" alt="image" src="https://github.com/user-attachments/assets/2e592de7-11cf-4ab4-8f81-b07546632299" />

VolumeHelper is a small macOS menu bar app.

It lets you change the most common audio settings directly from the menu bar:

- choose the input device
- choose the output device
- adjust input volume
- adjust output volume

That way, simple audio changes do not require opening System Settings.

## Download

The finished app is provided as a release.

After downloading:

1. Unzip the app
2. Move it to Applications
3. Start VolumeHelper

## Development

Open the project in Xcode and run the `VolumeHelper` target.
