VolumeHelper is a small macOS menu bar app.

It lets you change the most common audio settings directly from the menu bar:

- choose the input device
- choose the output device
- adjust input volume
- adjust output volume

That way, simple audio changes do not require opening System Settings.

## Download

The finished app is provided as a release. (The app is distributed as a notarized release.)

After downloading:

1. Unzip the app
2. Move it to Applications
3. Start it from app folder (it has no autostart, i dont like autostart apps haha)

## Development

Open the project in Xcode and run the `VolumeChangerForMenueBar` target.
